This is a machine learning-based web app built using Streamlit that classifies text messages as either spam or ham (non-spam). The app uses a pre-trained model to predict whether a given message is spam based on its content.

Features:
Text Input: Users can input any message for classification.

Prediction Output: The app classifies the message as either spam or ham.

Technology Stack: Python, Streamlit, scikit-learn, NLTK, and pickle for model serialization.

Purpose:
This project aims to demonstrate the use of machine learning in text classification, providing a simple but effective way to detect spam messages. It is built as a hands-on learning project to explore natural language processing (NLP) and machine learning techniques.
